# shontech.ru

Персональный сайт Дениса Шонова. Статический лендинг на GitHub Pages.

- `index.html` — главная страница (RU/EN)
- `lab.html` — ShonTech Lab: ИИ и цифровизация образования
- `fonts/`, `fonts.css` — шрифт Inter хранится локально, внешних CDN нет
- `books/` — обложки книг для секции «Книги»

Деплой: любой пуш в `main` автоматически публикуется на GitHub Pages.
